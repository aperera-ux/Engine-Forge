# Dyno / full-load curve sources (Engine Forge validation)

Curves live in `src/sim/validation/dynoCurves.ts`, engines in `referenceEngines.ts`
(EXTENDED set for engines outside the 21-engine peak-calibration set). Report:
`npx vitest run src/sim/__tests__/dynoCurves.test.ts`.
All curves are CRANK/ENGINE basis (OEM declared curves or crate-engine dyno charts). No wheel-dyno data was used,
so no drivetrain-loss conversion was applied. hp is always derived as Nm*rpm/7121 (mechanical hp).

## Searched, found nothing usable (do not repeat)

* Web search for full curves of Coyote (Ford Performance crate pages give only peak numbers), SkyActiv-G 2.5 (owner's manual/peak figures only), EJ257 STI (peak figures + modified-car chassis dyno), K20A, F20C, 4A-GE, 2JZ-GTE: no OEM/engine-dyno curve found.
* Wikimedia Commons: no engine torque/power SVG for any of K20A/F20C/2JZ/4A-GE/EJ257/RB26/SR20 (only Chrysler A831 turbine and electric-motor files).
* Mercedes-AMG M178 / Porsche / Ferrari press kits: web search returned only peak figures (Wikipedia, paultan, MBUSA release).
* Self Study Programmes whose chart is a RASTER image and were not traced yet: 822703 / 388 (4.2 V8 FSI "BAR"), 823603 and 924603 (3.2/3.6 VR6/V6 FSI), 279 (2.0 FSI, no chart data in text), 255 (2.0/3.0 5V).
* SSP 267 6.0 W12 (AZC) was digitised (vector) but NOT added: the simulator has no W layout (inline|v|flat only), so a 'v' config would misrepresent it.
* BMW training PDFs S55, S63TU, S62, B46, N63TU2, M54, N52, N26: no full-load diagram found by text search (charts, if any, are raster without caption text). N73B60 (ST047 "1 N73 Engine", p.5 "Power and Torque Output N73B60 / M73B54") has a raster chart, not yet traced.
* Newer Chevrolet Performance catalog at chevroletperformanceengines.davisgm.ca: it is a Wix dealer store with only product pages (no catalog PDF link on the home, category or product pages). The official 2022/2024 catalog PDFs are only on dcatalog.com flipbooks (now 'Content is no longer available'), Scribd, pdfcoffee, fliphtml5. The same dyno charts are available as GIFs straight from chevrolet.com engine pages (see table) so the catalog is no longer needed. Not found on chevrolet.com: LT5, LT376, LS7/LSA/LS9 (no dyno chart gifs on engine pages tried).
* Ford Performance Coyote / Aluminator crate engines and Mopar Hellcat / 392 crate: web search returns only peak numbers (460 hp @ 7000 / 420 lb-ft @ 4600 Gen 3; 480 hp Gen 4; Hellcat 707 hp / 650 lb-ft) and retailer listings; no published dyno chart or spec sheet with a curve found. Not pursued further (Godzilla 7.3, Hellephant likewise not found).
* SSP 824803 (2.0 TSI CCTA/CBFA) and 921703: vector chart but identical curve to SSP 922903 (already used for vw-ea888-gen1-20tfsi, CAEB = same 147 kW / 280 Nm plateau); not added as a duplicate. SSP 401 (1.8 TFSI BYT) is the same engine as SSP 384 (already used). SSP 195 2.3 V5 AGZ has a vector chart (NA VR5, 110 kW @ 6000 / 220 Nm @ 3600) but was not digitised (15 deg VR layout not representable). SSP 823603/924603 3.2/3.6 FSI V6 charts: raster, both curves share an unlabelled left axis (125-250) and the legend says hp blue / lb-ft red with an inconsistent right axis; the plateau (265 lb-ft) reads ~252 on the left axis, so the axes cannot be trusted -> rejected.
* chevrolet.com crate pages: LT5, LT376, LS7, LSA, LS9, LS3, LS376 pages exposed no dyno-chart GIF (LS3/LSA/LS7/LS9/LS376 already covered by the 2017 catalog; LT5/LT376 not found).
